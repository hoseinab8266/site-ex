تغییرات بخش مدیریت کاربران

- صفحه /admin/members اکنون کاربران ذخیره‌شده در سمت سرور را نمایش می‌دهد.
- API مدیریت کاربران در app/api/admin/members/route.ts قرار دارد و فقط برای نقش manager در دسترس است.
- اطلاعات کاربران در data/users.json ذخیره می‌شود و رمزها به صورت hash ذخیره می‌شوند.
- تصاویر کاربران در public/uploads/members ذخیره می‌شوند.
- ثبت‌نام کاربران نیز حساب را در فایل کاربران ذخیره می‌کند و ورود از همان فهرست حساب‌ها استفاده می‌کند.

نکته مهم برای استقرار:
این پیاده‌سازی برای سرور Node.js با دیسک پایدار و یک نمونه برنامه مناسب است. در سرویس‌های serverless یا استقرار چندنمونه‌ای، فایل‌های محلی ممکن است پایدار/مشترک نباشند؛ برای آن حالت باید ذخیره کاربران و تصاویر به دیتابیس و فضای ذخیره‌سازی پایدار منتقل شود.
