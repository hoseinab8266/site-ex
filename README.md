# پلیرز (Polyrez)

فروشگاه آنلاین شرکت دانش‌بنیان آتیه رزین شریف — مواد پلیمری و رزین‌های صنعتی.

سایت با **Next.js 15**، **React 19**، **TypeScript** و **Tailwind CSS v4** نوشته شده است. رابط کاربری فارسی و راست‌به‌چپ است و فونت وزیرمتن به‌صورت محلی از `app/fonts/Vazirmatn.woff2` بارگذاری می‌شود.

## راه‌اندازی

```bash
npm install
cp .env.example .env.local   # مقادیر را تکمیل کنید
npm run dev                  # http://localhost:3000
```

دستورهای دیگر:

```bash
npm run build       # ساخت نسخه تولید
npm run start       # اجرای نسخه ساخته‌شده
npm run typecheck   # بررسی نوع‌ها با tsc
```

## ساختار پروژه

```
app/            مسیرها، صفحات و API Routes
components/     اجزای رابط کاربری
lib/            منطق سمت سرور و داده‌ها
data/           پایگاه‌داده فایل‌محور (JSON)
public/         دارایی‌های ثابت و آپلودها
```

## ذخیره‌سازی داده

پشت‌بند این نسخه فایل‌محور است و در پوشه `data/` ذخیره می‌شود:

| فایل | محتوا |
| --- | --- |
| `data/catalog.json` | محصولات و مقالات |
| `data/users.json` | حساب‌های کاربری |
| `data/orders.json` | سفارش‌ها |
| `data/proformas.json` | درخواست‌های پیش‌فاکتور |
| `data/messages.json` | پیام‌های تماس و مشاوره |

هر فایل با نوشتن اتمیک (فایل موقت + rename) به‌روزرسانی می‌شود. تصاویر آپلودشده در `public/uploads/` قرار می‌گیرند.

## متغیرهای محیطی

تنظیمات مهم در `.env.example` مستند شده‌اند: `SESSION_SECRET`، `OTP_SECRET`،`ADMIN_*` و تنظیمات سرویس بله (`BALE_SAFIR_ACCESS_KEY`، `BALE_BOT_ID`).

### امنیت پنل مدیریت

ورود کارکنان از ورود مشتریان جداست: صفحهٔ `/admin/login` (یا مسیر پنهان) + رمز عبور، و برای مدیر یک مرحلهٔ دوم با **Google Authenticator**.

| متغیر | کارکرد |
| --- | --- |
| `ADMIN_LOGIN_PATH` | مسیر پنهان ورود کارکنان؛ با تنظیم آن، نشانی `/admin/login` با خطای ۴۰۴ پنهان می‌شود و ورود فقط از مسیر دلخواه (مثلاً `panel-x7k9`) ممکن است. خالی = رفتار عادی. |
| `ADMIN_ALLOWED_IPS` | فهرست سفید IP برای همهٔ مسیرهای مدیریتی و ورود کارکنان (با کاما). پیشوند با `*` پشتیبانی می‌شود (مثل `82.99.*`). خالی = بدون محدودیت. |
| `ADMIN_TOTP_REQUIRED` | پیش‌فرض `true`؛ اگر `false` شود، مدیر می‌تواند بدون فعال‌سازی ورود دومرحله‌ای وارد شود (توصیه نمی‌شود). |

نکته: مقدار `ADMIN_LOGIN_PATH` و `ADMIN_ALLOWED_IPS` در زمان ساخت (build) خوانده می‌شوند؛ پس از تغییر، پروژه را دوباره build کنید.

**ورود دومرحله‌ای:** در پنل → «امنیت حساب» → کد QR را با Google Authenticator اسکن کنید و کد ۶ رقمی را تأیید کنید. ۱۰ کد پشتیبان یک‌بار نمایش داده می‌شود؛ آن‌ها را جای امنی نگه دارید. دکمهٔ «غیرفعال کردن» نیازمند رمز عبور است.

بستهٔ `qrcode` در `optionalDependencies` است؛ اگر نصبش نکنید همه‌چیز کار می‌کند، فقط به‌جای تصویر QR کلید متنی و آدرس `otpauth://` نشان داده می‌شود (برای نصب: `npm i qrcode`).

**ابطال نشست:** با تغییر رمز عبور یا تغییر وضعیت ورود دومرحله‌ای، همهٔ نشست‌های قبلی باطل می‌شوند. نشست کارکنان حداکثر ۱۲ ساعت اعتبار دارد.

## حساب‌های پیش‌فرض (فقط محیط توسعه)

| نقش | نام کاربری | رمز عبور |
| --- | --- | --- |
| مدیر | `admin` | `Polyrez@1405` |
| عضو شرکت | `sales` | `Sales@1405` |
| خریدار | `09120000000` | `Buyer@1405` |

> پیش از انتشار، حتماً مقادیر `ADMIN_*` را عوض کنید و `SESSION_SECRET` واقعی تنظیم کنید.

## نکته درباره داده‌های نمونه

بخشی از متن‌ها و اعداد (توضیحات محصولات، مقالات، اطلاعات تماس) با کامنت `⚠️` علامت‌گذاری شده‌اند و باید با اطلاعات واقعی شرکت جایگزین شوند.
